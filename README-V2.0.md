# Liste de courses de saison V2.0 CLEAN

Reconstruction en un seul document HTML, avec une feuille de style unique, un seul catalogue de 31 recettes et un seul module JavaScript.

Pour GitHub Pages, renommer le fichier HTML en `index.html`. La V2 utilise une nouvelle clé de stockage locale `grocerySeasonV2` et ne récupère pas automatiquement les données des anciennes versions.
